# Описание проекта

Проект Планировщик задач (аналог TODO-листа), реализуемый на веб-сервере.

Планировщик хранит задачи, каждая из которых содержит дату дедлайна, название и комментарий к задаче.
Задачи могут повторяться по заданному правилу: например, ежегодно, через какое-то количество дней, в определённые дни месяца или недели.
Если отметить такую задачу как выполненную, она переносится на следующую дату в соответствии с правилом. 
Обычные задачи при выполнении сразу удаляются.

# Реализованные задачи со звездой

1. Определение порта через переменную окружения
2. Определение пути к файлу базы данных через переменную окружения
3. Повтор задачи в указанные дни недели, дни месяца
4. Поиск по текущему списку задач
5. Аутентификация по паролю, определяемому через переменную окружения
6. Возможность запуска проекта в Docker

# Переменные окружения

TODO_PORT                       # порт сервера (по умолчанию: 7540)
TODO_DBFILE                     # файл БД (по умолчанию: scheduler.db)
TODO_PASSWORD                   # пароль для входа (по умолчанию не задан)
JWT_SECRET                      # секретный ключ для JWT (по умолчанию для упрощения "go_final_project_secret_key")

Авторизация включается, только если TODO_PASSWORD != "".
JWT_SECRET нужен только для подписи JWT-токена. Если не задан, используется дефолтный ключ.
Если TODO_PASSWORD == "", то JWT_SECRET игнорируется, авторизация не требуется.


# Сборка образа проекта в Docker

docker build -t todo-app .

# Запуск планировщика в Docker-контейнере (без переменных окружения)

docker run -p 7540:7540 \
  -v $(pwd)/scheduler.db:/app/scheduler.db \
  todo-app

После запуска контейнера планировщик запускать в браузере:

http://localhost:7540

# Запуск планировщика в Docker-контейнере (пример с разными переменными окружения)

docker run -p 8081:8081 \
  -e TODO_PASSWORD=12345 \
  -e TODO_PORT=8081 \
  -e JWT_SECRET=another_secret \
  -v $(pwd)/scheduler.db:/app/scheduler.db \
  todo-app

После запуска контейнера планировщик запускается в браузере по адресу:

http://localhost:8081, где браузер запросит пароль и авторизирует при вводе 12345 

! Токен авторизации хранится 8 часов, браузер будет сохранять сессию, далее потребуется повторная авторизация

! Если пароль или секретный ключ были изменены, то браузер сразу запросит повторную авторизацию

# Запуск планировщика локально из каталога проекта

go run main.go
